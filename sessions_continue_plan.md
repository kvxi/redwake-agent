When this agent harness is run, a new session is stored in its standard location. Within a session, a user can run /tree to go back and branch messages within this session. Add a new slash command: /sessions which will list sessions in order. User can navigate up and down and hit enter on it to start a new message which has a parent set to the latest message in that session. Some logic for this feature can be reused: the /tree command already rebuilds context from message history, and going back to an old sessions can use similar logic to rebuild context from the message history.
